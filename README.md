# Keepsake - Responsive Landing Page

Адаптивний односторінковий лендінг для дизайн-агенції Keepsake, виконаний відповідно до макета Figma та вимог лабораторної роботи №7 (Завдання 4).

## Посилання на демо
- **GitHub Pages:** [https://<username>.github.io/landing-keepsake/](https://github.com)

## Використані технології
- **HTML5:** семантична розмітка (`header`, `nav`, `main`, `section`, `article`, `footer`, `form`), валідна структура за стандартом W3C, один заголовок `h1`, доступність (ARIA атрибути).
- **CSS3:** чистий CSS без використання сторонніх фреймворків чи UI-бібліотек.
- **Підхід Mobile First:** базові стилі для мобільних екранів від 320px, далі розширення через `@media (min-width: 768px)` та `@media (min-width: 1280px)`.
- **Flexbox & Grid:** гнучка розкладка блоків без абсолютного позиціонування для основної сітки.
- **CSS Змінні (`:root`):** винесення всіх дизайн-токенів кольорів, шрифтів та базових відступів.
- **Google Fonts:** підключення шрифтів Oswald, Open Sans та Dancing Script із оптимізацією `font-display: swap`.
- **SVG & WebP:** векторні інлайн-іконки та растрові зображення у форматі WebP із атрибутами `width`, `height` та `loading="lazy"`.

## Особливості реалізації
1. **Мобільне меню:** реалізовано на чистому CSS без використання JavaScript (CSS checkbox hack), плавна трансформація кнопки-бургера у хрестик.
2. **Фільтр портфоліо:** перемикання категорій робіт (All, Branding, Identity, Print, Web, Motion) виконано за допомогою CSS-селекторів `:checked ~`.
3. **Ховер карточок:** ефект затемнення із виведенням назви, бірюзової кнопки «+» та категорії; підтримка клавіатурної навігації через `:focus-visible` та `:focus-within`.
4. **Форма підписки:** стилізація станів `focus` та `error`, обов'язкова валідація електронної адреси та згоди з правилами.
5. **Фіксований Header та кнопка «Вгору»:** фіксація навігаційної панелі під час прокручування сторінки та постійна доступність кнопки швидкого повернення нагору.
